# Plugin Risk Matrix

| Risk | Examples | Mitigation |
|---|---|---|
| Over-denoise | Bertom pushed too hard | A/B with source, use candidate A/B/C |
| Vocal identity change | GSnap, Graillon | Disabled by default |
| Tone overcorrection | TDR Nova deep cuts | Level-match and bypass often |
| Broken consonants | De-esser too strong | Check S/T/K/P/CH phrases |
| Fake quality improvement | LoudMax masking balance issues | Use only as safety limiter |
| Installer/account friction | Optional bundles | Manual install only |
| Plugin scan failure | REAPER does not discover VST3/AU | Verify paths and rescan on main computer |
| Public PC contamination | Downloads or licenses on shared machine | Never execute install here |
