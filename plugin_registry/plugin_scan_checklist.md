# Plugin Scan Checklist

Run only on the main computer.

1. Confirm installed plugin folders.
2. Open REAPER preferences.
3. Verify VST3/AU paths.
4. Clear/re-scan only if needed.
5. Search FX browser for each plugin.
6. Add plugins to a dummy project.
7. Save a plugin inventory report.
8. Do not test with real audio until dummy scan passes.

Expected plugin roles:

- Denoise: Bertom Denoiser Classic
- Dynamic EQ: TDR Nova
- De-ess: Techivation T-De-Esser 2
- Metering: Voxengo SPAN, Youlean
- Safety limiting: LoudMax
