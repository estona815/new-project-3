# Public PC Rules

This repository may be edited on a public/shared company computer only under strict harness-only rules.

## Allowed

- Create documentation.
- Create dry-run install scripts.
- Create placeholder templates.
- Create REAPER Lua automation stubs.
- Create QC report stubs.
- Run safety verification scripts.
- Commit text-only harness files if Git is available and the repo is clean.

## Banned

- No REAPER extension installation.
- No audio plugin installation.
- No DAW account login.
- No GitHub account login.
- No iLok login.
- No Soundtoys, Valhalla, Plugin Alliance, Antares, Suno, or music account login.
- No real audio processing.
- No private audio storage.
- No downloaded AI models.
- No licenses, serial numbers, activation files, API keys, cookies, or tokens.
- No unreleased artist material.
- No personal files.

## Public PC Completion Standard

A public PC session is successful only if:

- No install command was executed.
- No real audio files exist in the repo.
- No secrets are detected by the local scanners.
- `reports/bootstrap_report.md` states that work was harness-only.
