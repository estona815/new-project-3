# Noise Reduction Plugins

## Bertom Denoiser Classic

Role: conservative broadband noise reduction.

Use it gently. The goal is less hiss/fizz/noise, not a stripped or underwater vocal. Print A/B/C candidates and keep a parallel source blend available.

Rules:

- Start with minimal reduction.
- Stop before consonants smear.
- Do not use denoise to fix mix balance.
- If artifacts appear, back off or skip denoise.
