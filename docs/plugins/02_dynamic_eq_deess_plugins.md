# Dynamic EQ And De-Ess Plugins

## TDR Nova

Role: dynamic EQ for fizz, harshness, low-mid mud, and resonance control.

## Techivation T-De-Esser 2

Role: de-ess and high-frequency harshness control.

Policy:

- Dynamic EQ comes after conservative denoise.
- De-ess must not break S/T/K/P/CH articulation.
- Level-match before deciding a candidate is better.
