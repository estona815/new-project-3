# Plugin Layer Overview

The plugin expansion layer adds a safe, Git-managed plan for free/recommended REAPER plugins that may help Suno vocal repair on the main computer.

Public PC mode remains documentation-only:

- no plugin install
- no installer download
- no account login
- no REAPER plugin scan
- no real audio

Plugin groups:

- Core: denoise, dynamic EQ, de-ess, metering, safety limiting
- Recommended: body restoration and gentle compression
- Optional: space, utility bundles, specialist tools
- Disabled by default: pitch correction tools that can change identity
