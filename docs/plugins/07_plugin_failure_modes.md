# Plugin Failure Modes

- Plugin scan fails in REAPER.
- Plugin installs to a folder REAPER does not scan.
- Plugin requires account login or activation.
- Plugin changes vocal identity.
- Denoise creates watery artifacts.
- Dynamic EQ hollows the vocal.
- De-ess breaks consonants.
- Saturation exaggerates AI fizz.
- Compression brings up noise.
- Limiting hides balance problems.

If any of these occur, stop and write a failure note before continuing.
