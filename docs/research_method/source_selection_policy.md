# Source Selection Policy

This knowledge base uses public resources as references for building original workflow rules. It does not copy source content into the repository.

## Priority Order

1. Prefer official DAW manuals and plugin documentation first.
2. Prefer recent, reputable engineering articles second.
3. Use YouTube lessons only when they provide clear, actionable mixing technique.
4. Use community tips only when they can be confirmed by multiple reliable sources.

## Reject Sources That

- Promote cracked plugins, unsafe downloads, or license bypasses.
- Depend on private course content, paywalled transcripts, or copied training dumps.
- Encourage artist-copying, vocal cloning, soundalike replication, or identity imitation.
- Offer random "secret sauce" advice that cannot become a measurable or listenable rule.
- Require downloading copyrighted audio, video, or stems.

## Focus Topics

Capture transferable engineering concepts:

- EQ
- Compression
- De-essing
- Saturation
- Loudness
- Stereo
- Reference checking
- Vocal balance
- Mixbus safety

## Acceptance Test

A source is useful only if its lesson can be converted into at least one of:

- A REAPER action step
- A plugin-chain rule
- A QC rule
- A Suno vocal repair rejection condition
