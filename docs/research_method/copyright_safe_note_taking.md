# Copyright-Safe Note Taking

The repository stores original operational knowledge, not copied source material.

## Allowed

- Source link and metadata
- Timestamp notes for videos
- Short paraphrased summaries
- Original workflow conclusions
- Short fragments only when truly needed for attribution or precision
- REAPER-specific rules written in our own words

## Not Allowed

- Large copied passages
- Full articles
- Full transcripts
- Downloaded videos
- Downloaded audio
- Copied course worksheets or paywalled lessons
- Private stems, references, renders, or session media

## Transformation Rule

Every lesson should be transformed into an original operational rule:

1. Identify the problem the source addresses.
2. Extract the technique at a high level.
3. Translate it into REAPER chain logic.
4. Add failure modes and rejection conditions.
5. Add a QC check that can be heard, measured, or both.

If a note cannot be transformed into a workflow rule, leave it as source metadata only.
