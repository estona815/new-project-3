# YouTube Note Policy

YouTube videos are source references, not training data dumps.

## Do Not

- Download video.
- Download audio.
- Commit subtitles or transcripts unless the creator explicitly allows it and attribution is included.
- Copy long spoken passages.
- Recreate paid course content.

## Store Only

- Video title
- Creator/channel
- URL
- Timestamp notes
- Short original summary notes
- Actionable workflow conclusions

## Extract Only

For each useful timestamp, extract:

- Problem
- Technique
- Plugin type
- Parameter idea
- Failure risk
- REAPER translation
- QC rule

## Required Output Shape

YouTube notes must become lesson cards, then REAPER rule cards. If a video only provides vague taste advice, do not convert it into an automation rule.
