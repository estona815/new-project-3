# Reference Targeting

The reference targeting system translates user taste notes into practical production targets.

It supports text such as `love blur 느낌 드럼`, `emotional hyperpop but not too rage`, or `digicore melody, clean 808, less generic trap`. Optional reference WAV audio can add broad measurements such as onset density, brightness, low-end weight, dynamic range, energy curve, stereo width, and transient sharpness.

## Safety Policy

- Reference output is reference-inspired, not an exact clone.
- The system does not recreate protected melodies, samples, lyrics, or unique sound recordings.
- Audio analysis does not extract exact drum patterns or melodies.
- Style matching is a high-level production checklist for Logic Pro and post-production decisions.

## Outputs

- `08_REFERENCE_MATCH/reference_target_profile.json`
- `08_REFERENCE_MATCH/style_translation.md`

Use `style_translation.md` as a manual Logic checklist for drum feel, 808 tone, vocal placement, arrangement movement, and mix/master direction.
